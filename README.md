# জমা-খরচ (Joma-Khoroch) - GitHub Pages গাইড

এই ফোল্ডারের ফাইলগুলো দিয়ে আপনি খুব সহজেই আপনার নিজের GitHub অ্যাকাউন্টে সম্পূর্ণ বিনামূল্যে এই নতুন ও উন্নত ওয়েবসাইটটি হোস্ট করতে পারবেন।

## 📁 তৈরি করা ফাইলসমূহ:
1. `index.html` - মূল ওয়েবসাইট পেজ (Date-to-Date সার্চ, ক্যাটাগরি বিশ্লেষণ, ফর্ম ও ফিল্টারসহ)
2. `style.css` - রেসপন্সিভ ডিজাইন ও এমারেল্ড গ্রিন থিম
3. `app.js` - সম্পূর্ণ লজিক, লোকালস্টোরেজ সেভ, CSV এক্সপোর্ট ও PIN সিকিউরিটি
4. `manifest.json` - মোবাইল ওয়েব অ্যাপ (PWA) কনফিগারেশন

---

## 🚀 GitHub Pages-এ লাইভ করার সহজ ধাপসমূহ:

### ধাপ ১: GitHub-এ লগইন ও নতুন Repository তৈরি
1. আপনার ব্রাউজারে [github.com](https://github.com)-এ যান এবং লগইন করুন।
2. উপরের ডানদিকের **`+`** আইকনে ক্লিক করে **New repository** সিলেক্ট করুন।
3. Repository name দিন (যেমন: `joma-khoroch` অথবা আপনার পছন্দমতো নাম)।
4. এটিকে **Public** রাখুন।
5. **Add a README file** বক্সে টিক দিয়ে **Create repository** বাটনে ক্লিক করুন।

### ধাপ ২: ফাইলগুলো আপলোড করা
1. আপনার নতুন রিপোজিটরির পেজে **Add file** -> **Upload files** অপশনে ক্লিক করুন।
2. `web` ফোল্ডারের ভেতরের এই ফাইলগুলো সিলেক্ট করে আপলোড করে দিন:
   - `index.html`
   - `style.css`
   - `app.js`
   - `manifest.json`
3. নিচে **Commit changes** বাটনে ক্লিক করে ফাইলগুলো সেভ করুন।

### ধাপ ৩: GitHub Pages চালু করা
1. রিপোজিটরির উপরের মেনু থেকে **Settings** ট্যাবে যান।
2. বাঁপাশের মেনু থেকে **Pages** অপশনে ক্লিক করুন।
3. **Build and deployment** সেকশনে:
   - **Source:** সিলেক্ট করুন `Deploy from a branch`
   - **Branch:** সিলেক্ট করুন `main` (বা `master`) এবং ফোল্ডার হিসেবে `/ (root)` রাখুন।
4. **Save** বাটনে ক্লিক করুন।

### ধাপ ৪: ওয়েবসাইট দেখা
১-২ মিনিট পর পেজটি রিফ্রেশ করলে উপরে দেখতে পাবেন:
> **"Your site is live at https://<আপনার-ইউজারনেম>.github.io/<রিপোজিটরির-নাম>/"**

এখন লিংকটিতে ক্লিক করলেই আপনার নতুন Date-to-Date এবং ক্যাটাগরি রিপোর্টসহ সম্পূর্ণ জমা-খরচ অ্যাপটি ইন্টারনেটে লাইভ চালু হয়ে যাবে!
